# Critical Review of ML and Deep Learning for Loan Prediction in Banking

**Academic research critique | February-April 2025 | ECE 535, University of Victoria**

**Coauthors: Taimoor Shahzad and Inderjit Singh.** This was a two-person project; the critique and its conclusions are presented as joint work.

This project critically reviews a 2024 IEEE Access paper comparing machine learning, deep learning, ensemble methods, and data-balancing techniques for loan default prediction. It examines whether the paper's dataset, model choices, evaluation, and reporting support its claims and practical use in banking.

The work is a paper review, not a deployed lending model. This repository contains the public critique report and supporting research materials; it does not provide a model implementation, trained weights, or an independently reproduced benchmark.

## Read the critique

Start with the [public final report](ECE535%20FINAL%20PROJECT%20REPORT-Public.pdf). Its sections cover the introduction, dataset collection and processing, feature selection, classification algorithms, performance evaluation, conclusions, and references.

## Review themes

| Area | Questions and concerns examined in the report |
| --- | --- |
| Dataset quality and representativeness | Whether the source data reflects real lending conditions; unusual marital-status proportions and age-experience combinations; generalization beyond a single dataset. |
| Class imbalance and preprocessing | The use of SMOTE and SMOTE-Tomek; scaling and categorical encoding; transparency of outlier handling and validation of preprocessing effects. |
| Features and assumptions | Missing credit-related variables, feature validation, and the independence assumption of Gaussian Naive Bayes. |
| Model suitability | The justification for applying CNN, ResNet, DenseNet, and autoencoder architectures to tabular financial data, alongside traditional classifiers and ensemble methods. |
| Reproducibility | Whether model configurations, hyperparameters, regularization, and training details are reported clearly enough to reproduce results. |
| Evaluation | Class-specific performance, overfitting concerns, metric trade-offs, and evidence that reported performance transfers to realistic lending data. |
| Explainability and deployment | Whether SHAP/LIME claims are supported by concrete results; fairness across demographic and geographic groups; training time, memory use, and computing constraints. |

These are the coauthors' assessments in the report. The repository does not present the reviewed paper's performance numbers as results achieved by this project.

## Supporting dataset

The archive contains:

| File inside the archive | Rows | Role |
| --- | ---: | --- |
| `Training Data.csv` | 252,000 | Features and the `Risk_Flag` label. |
| `Test Data.csv` | 28,000 | Features without a default-risk target column. |
| `Sample Prediction Dataset.csv` | 28,000 | Supplied sample prediction/submission file with `id` and `risk_flag` columns. |

The training file contains 221,004 rows labeled `0` and 30,996 labeled `1`, matching the class counts discussed in the critique. The archive's sample prediction file is supplied reference material, not predictions generated by the coauthors.

The dataset source cited in the report is [Loan Prediction Based on Customer Behavior on Kaggle](https://www.kaggle.com/datasets/subhamjain/loan-prediction-based-on-customer-behavior). Dataset attribution and terms remain with the original provider.
